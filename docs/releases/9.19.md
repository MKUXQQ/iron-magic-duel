# Iron Magic Duel 9.19

适用于 Minecraft 1.21.1 NeoForge。客户端与服务器必须安装同一个 JAR。

## 新功能

- `/spell_duel duel <玩家>` 单挑邀请、接受/拒绝和空闲 `duel_N` 场地选择。
- 玩家交互器：右键玩家可发起单挑或查看其 Curios 法术书栏内当前法术。
- 多个 `duel_N` 场地独立占用，场地释放后才可再次选择。
- 管理员玩家选择器可强制结束目标的新单挑并立即恢复双方状态。
- `/spell_duel surround lock` 与 `/spell_duel surround release` 环形禁锢。

## 兼容与稳定性

- 改进持续喷雾伤害频率、主动取消冷却和附属喷雾兼容。
- 修复雪球、冰霜射线与冰川刃等冻结链路，并保护玩家伤害无敌帧。
- 修复决斗死亡、复活、延迟恢复与管理员重新分队之间的状态冲突。
- 环形禁锢只处理会话玩家，安全落点失败采用有限重试，不进行全服实体扫描。

## 安装

1. 安装 NeoForge 21.1.233 或更高的 21.1.x 版本。
2. 安装 Iron's Spells 'n Spellbooks 1.21.1-3.16.2 或更高版本。
3. 安装 Curios API 9.5.1+1.21.1。
4. 将 `iron_magic_duel-9.19.jar` 同时放入客户端和服务器的 `mods` 文件夹。
