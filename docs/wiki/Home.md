# Iron Magic Duel

Iron Magic Duel 是面向 Minecraft 1.21.1 NeoForge 与 Iron's Spells 'n Spellbooks 的多人法术竞技模组。

当前版本：**9.19**

## 核心功能

- 多个 `duel_1`、`duel_2`、`duel_N` 独立决斗场地。
- 管理员组队决斗、普通玩家单挑邀请与观战系统。
- 玩家交互器：发起单挑或查看目标 Curios 法术书栏中的实际法术。
- 商店、禁法区域、赛事 HUD、点位工具和管理员玩家选择器。
- 环形禁锢、冻结/喷雾/冷却兼容及服务端性能保护。
