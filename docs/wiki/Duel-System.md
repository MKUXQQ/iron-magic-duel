# 决斗与单挑系统

## 管理员组队决斗

1. 使用 `/spell_duel tool` 获取玩家选择器和点位工具。
2. 设置决斗组的 A/B 点位。
3. 使用玩家选择器将玩家加入 A 队或 B 队。
4. 使用 `/spell_duel start duel_1` 开始比赛。

管理员玩家选择器优先级最高。目标正在参与新单挑、等待接受、等待选点或处于获胜延迟恢复时，选择器会先强制结束并恢复对应新单挑，再继续旧决斗分队。

## 玩家单挑

玩家可使用以下任一方式发起邀请：

- `/spell_duel duel <玩家>`
- 手持玩家交互器右键目标，选择“单挑”

目标接受后，由发起者选择空闲的 `duel_N` 场地。每个场地独立占用：`duel_1` 正在使用时仍可选择空闲的 `duel_2`；全部场地占用时不能开始新单挑。

## 查看法术

玩家交互器右键目标并选择“查看法术”，显示目标 Curios `spellbook` 槽位中当前装备法术书的有效法术。数据由服务端读取；未装备法术书和空法术书会分别提示。

## 结束与恢复

- 失败者使用原版死亡与重生流程。
- 胜利者短暂展示后恢复进入决斗前的位置和状态。
- 场地只有在战斗真正结束并释放后才能再次选择。
- A/B 点位长期保留，可重复使用。
