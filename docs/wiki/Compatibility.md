# 兼容与战斗规则

9.19 包含针对 Iron's Spells 'n Spellbooks 与附属法术的赛事兼容调整：

- 保护玩家原版伤害无敌帧，法术不能叠加暴击伤害。
- 持续喷雾统一提高有效伤害频率，并支持再次按键主动取消与进入原生冷却。
- 管理雪球、冰霜射线、刺骨寒风和冰川刃的冻结时长与释放清理。
- 禁用赛事法术及已适配附属的玩家镜头晃动。
- 修正部分法术的伤害、吸血、召唤物、牵引和投射物行为。
- 服务器热路径只遍历已登记活动状态；空状态快速返回，避免全世界实体扫描。

部分功能依赖整合包内对应附属模组；未安装可选附属时，相应兼容注入不会生效。

- `latest.log`
- `debug.log`
- 崩溃报告（如有）
