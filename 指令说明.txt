铁魔法决斗（Iron Magic Duel）
指令与功能说明
版本：1.0.39
适用版本：Minecraft 1.21.1 / NeoForge 21.1.233

一、权限说明

以下标记“管理员”的指令需要权限等级 2。
普通玩家可以使用观战和 HUD 位置指令，但不能修改决斗配置。

二、决斗工具

/spell_duel tool
管理员指令。给当前玩家发放：玩家选择器、点位选择器。

玩家选择器使用方法：
1. 右键玩家：将玩家加入 A 组。
2. 左键玩家：将玩家加入 B 组。
3. 蹲下右键空气：使用当前选择的玩家创建一个新的决斗组。
4. 被选中的玩家会发出绿色发光效果。
5. 创建决斗组后，选择器的绿色发光效果会消失。
6. 选中玩家和创建决斗组时会播放提示音效。

点位选择器使用方法：
1. 右键方块：临时设置 A 点位。
2. 左键方块：临时设置 B 点位。
3. 蹲下右键空气：将两个临时点位保存并绑定到当前决斗组。
4. 已保存的点位会一直保留，不会因为决斗胜利或结束而自动删除。

三、用指令设置点位

/spell_duel point <决斗组ID> a
/spell_duel point <决斗组ID> b

管理员指令。将当前执行者所在的世界、坐标和视角保存为指定决斗组的 A 或 B 点位。
点位会保存到世界存档中，必须使用 clear point 指令才会删除。
决斗组不存在、已经开始或无法修改时，指令会失败并提示原因。

四、开始决斗

/spell_duel start <决斗组ID>
管理员指令。开始指定决斗组，将 A 组和 B 组玩家传送到各自点位。

/spell_duel start all
管理员指令。开始所有符合条件的决斗组。

开始时会保存每位对战玩家原来的世界、坐标、视角和游戏模式。
决斗胜利后会立即显示获胜玩家的真实名称，不显示“A组”或“B组”。
胜利提示显示后，对战玩家还会留在场地内等待 5 秒；5 秒结束后自动返回原来的位置。
5 秒等待期间不能重新开始同一个正在返回的决斗组。

五、观战

/spell_duel spectate <决斗组ID>
进入指定正在进行中的决斗观战。

/spell_duel spectate leave
退出观战，并恢复观战前保存的世界、位置、视角和游戏模式。

观战者可以通过观战 HUD 查看对战玩家的：
1. 玩家头像和真实名称。
2. 当前法术图标。
3. 法术冷却时间。
4. 生命值和最大生命值。
5. 当前蓝量和最大蓝量。

六、HUD 显示

/spell_duel display on
管理员指令。开启对战 HUD/玩家显示同步。

/spell_duel display off
管理员指令。关闭对战 HUD/玩家显示同步。

/spell_duel hud <x> <y>
设置当前执行者 HUD 左上角的位置。x 和 y 使用屏幕像素坐标，范围为 0 到 10000。
示例：
/spell_duel hud 20 20

当前版本不再使用 /spell_duel hud position ...。
HUD 会自动限制在屏幕范围内，避免面板超出屏幕。
HUD 面板底板为不透明黑色，并使用黑色底板、灰色描边和蓝色蓝条样式。
玩家自己的 HUD 和观战 HUD 使用统一的蓝条样式。

七、商店

/spell_duel shop
管理员指令。给当前玩家发放：无限商店木桶、商店编辑器。

无限商店木桶：
1. 右键打开商店。
2. 商店共有最多 5 页。
3. 每页为大箱子大小，共 54 格。
4. 商店内的物品可以无限领取，不会被消耗。
5. 领取物品后商店会自动补回原来的物品。
6. 蹲下右键商店物品可以切换到下一页，切换时通过 subtitle 提示当前页数。
7. 到第 5 页后继续切换会回到第 1 页。

商店编辑器：
1. 右键打开编辑器。
2. 编辑器共有最多 5 页，每页 54 格。
3. 可以一次放入多个物品，所有放入的物品都会被保存。
4. 放入物品后会立即写入世界存档 JSON 文件。
5. 关闭编辑器后物品不会消失。
6. 重新打开编辑器会读取上一次保存的所有页和所有格子。
7. 编辑器中的物品可以取出、替换和修改；编辑器内的物品只允许编辑者正常取出一次。
8. 蹲下右键编辑器可以切换页面，切换时通过 subtitle 提示当前页数。

商店数据文件：
<世界存档>/data/iron_magic_shop.json

商店数据使用临时文件加替换方式保存，尽量避免保存过程中损坏原文件；旧版
iron_magic_shop.nbt 会在找不到 JSON 时自动迁移一次。

八、清理配置

/spell_duel clear all
管理员指令。清除所有决斗组及其玩家、点位配置。

/spell_duel clear group
管理员指令。清除所有决斗组中的玩家，但保留决斗组和点位。

/spell_duel clear group <决斗组ID>
管理员指令。清除指定决斗组中的玩家，但保留决斗组和点位。

/spell_duel clear point
管理员指令。清除所有决斗组的点位，并清除点位选择器临时点位。

/spell_duel clear point <决斗组ID>
管理员指令。清除指定决斗组的 A、B 点位。

注意：决斗结束、玩家获胜、商店关闭都不会自动清除已经保存的点位或商店内容。

九、假人

/spell_duel fake_players
管理员指令。按照服务端配置中的 fakePlayers 列表执行假人生成指令。
该功能依赖服务器已经安装并启用相应的假人/玩家生成命令。

十、铁魔法投射物重力

/ironspell gravity on
管理员指令。开启铁魔法投射物的无重力效果，并立即应用到已经存在的投射物。

/ironspell gravity off
管理员指令。关闭铁魔法投射物的无重力效果，并立即应用到已经存在的投射物。

/spellgravity on
/spellgravity off
上述指令的简写入口，功能与 /ironspell gravity on/off 相同。

十一、其他功能

1. 对战状态由服务器权威管理，玩家加入、传送、胜利和返回由服务端处理。
2. 决斗点位保存在世界存档中，服务器重启后仍然保留。
3. 玩家选择器会清理旧的临时选择，避免绿色发光状态残留。
4. 商店内容按世界存档保存，不同世界可以拥有不同商店。
5. 物品名称使用中文：无限商店、商店编辑器、玩家选择器、点位选择器。
6. 蓝量不是无限的，施法会正常消耗蓝量；HUD 会显示当前蓝量和最大蓝量。
7. 模组包含法术图标、冷却显示、HUD 平滑显示和性能辅助功能。

十二、安装

将 iron_magic_duel-1.0.39.jar 放入服务端和客户端的 mods 文件夹。
服务端和客户端都需要 Minecraft 1.21.1、NeoForge 21.1.233，以及项目声明的依赖模组。

十三、生命恢复规则（1.0.39）

玩家的饱和度会持续保持满格。
玩家受到伤害后，进入 10 秒自然回血等待时间；等待期间不能通过自然回血恢复生命值。
如果等待期间再次受到攻击，10 秒计时会重新开始。
连续 10 秒没有受到攻击后，才允许原版自然回血。
该规则适用于服务器上的玩家，包括对战玩家。

十四、玩家选择器在线列表（1.0.39）

普通右键玩家选择器会打开屏幕中央的在线玩家列表。
列表显示所有当前在线玩家的头像、名称，以及该玩家是否已经被其他决斗组选中。

列表操作：
1. 左键玩家：加入 A 队；再次左键同一玩家：取消选择。
2. 右键玩家：加入 B 队；再次右键同一玩家：取消选择。
3. 鼠标滚轮：浏览在线玩家列表。
4. 底部只有“创建对战”按钮，点击后创建决斗组并清除绿色发光效果。
5. 蹲下右键玩家选择器：关闭并取消当前所有玩家选择，不创建对战。
